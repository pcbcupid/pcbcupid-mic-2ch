# pcbcupid-mic-2ch
TDK ICS 43434 based 2CH I2S digital MIC, which can be used as a replacement for the obsolete INMP441 

<img src="https://files.pcbcupid.com/Documentation/Boards/g-sense/2ChMic/2-ch-gsense-microphone-ics43434.avif" alt="PCBCUPID-2CH-MIC" width="500" />

This repo contains open source PCB files for PCBCUPID GSense Touch Slider Module <br/>
This particular PCB is designed using Kicad v9.0

**This design has been built and tested successfully!**
For more details, check out the product pages at

   * [Gsesnse-2ch-mic](https://shop.pcbcupid.com/product/gs002/)
   * [Docs](https://learn.pcbcupid.com/boards/g-sense/ics43434-2ch)
